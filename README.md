 Path of the Immortal

Project Description
Path of the Immortal is a Flutter-based Choose Your Own Adventure game inspired by cultivation and martial arts fantasy stories. The player makes decisions throughout the story that affect the outcome and lead to multiple endings.

Features
- Multiple story paths
- Different endings (Good Ending, Bad Ending, Neutral Ending,one secret ending)
- Interactive choices
- Scene illustrations(AI GENERATED)
- Background music and sound effects
- Restart system

Technologies Used
- Flutter
- Dart
- Audioplayers package

 How to Run
1. Open the project in VS Code or Android Studio
2. Run:
   flutter pub get
3. Start the app using:
   flutter run

Project Requirements Completed
- 10+ story scenes
- 4+ decision points
- 3 different endings
- Multiple choices per decision
- Multimedia integration
